# local_kabfeedbackgdoc — ответы «Обратной связи» → Google-таблица

Каждый отправленный ответ в активности **Обратная связь** (mod_feedback) уходит
POST-ом в веб-приложение Google Apps Script, привязанное к Google-таблице, и
становится строкой в формате таблиц «Задать вопрос преподавателю … (Ответы)»
из папки основных вебинаров ОК:

`Отметка времени | Имя | Город | Буду участвовать в вебинаре | Мой вопрос | Номер группы | Email | Ссылка в Moodle | Форма | Ответ преподавателя`

Город — из профиля пользователя, «Номер группы» — группы курса, в которых он состоит.
Пункты формы раскладываются по колонкам по названию (`COLUMN_RULES` в скрипте):
«присутств/участв» → участие, «вопрос» → вопрос, остальное дописывается к вопросу.
Преподаватели отвечают в колонке «Ответ преподавателя».

## Как это устроено

```
студент отправляет форму
  → \mod_feedback\event\response_submitted
  → observer (фильтр по cmid из настроек) → adhoc-задача
  → cron: sender::build_payload() → curl POST JSON → Apps Script doPost()
  → SpreadsheetApp дописывает строку в таблицу
```

- Отправка **не** делается в запросе студента: observer только ставит adhoc-задачу,
  cron шлёт и при ошибке ретраит с back-off.
- Apps Script дедуплицирует по `completedid` (ScriptProperties), так что ретраи
  не плодят копии.
- Ответы отдаются через `feedback_item_base::get_printval()`, т.е. для multichoice
  приходит текст варианта, а не индекс.

## Настройки (Администрирование → Плагины → Локальные плагины)

| Настройка | Что |
|---|---|
| `enabled` | вкл/выкл |
| `webhookurl` | URL развёртывания Apps Script `…/exec` |
| `secret` | строка, совпадающая с `SECRET` в `Code.gs` (пусто = без проверки) |
| `courseids` | через запятую id курсов — пересылать все feedback из них; пусто = любой курс |
| `namepattern` | регулярка (без регистра) на название активности, напр. `вопрос`; пусто = любое |
| `cmids` | через запятую cmid активностей (параметр `id` в URL); пусто = не ограничивать |

Фильтры AND-ятся. Рабочая настройка: `courseids = 238`, `namepattern = вопрос`, `cmids` пусто —
новая еженедельная форма «Вопрос по теме урока N…» подхватывается без правки настроек.

**Повторная отправка.** У неанонимной «Обратной связи» «Разрешить несколько отправок» означает
*редактирование* прошлого ответа (та же запись `feedback_completed`, новый `timemodified`).
Скрипт дедуплицирует по `completedid:timestamp`, поэтому отредактированный ответ ложится
новой строкой, а ретрай cron той же доставки — нет.

**Редиректы.** Apps Script отвечает на POST 302 → `script.googleusercontent.com`, который принимает
только GET. Moodle-curl при эмуляции редиректов (open_basedir) повторяет POST и получает 405, поэтому
`sender::post()` не следует за редиректом, а сам делает GET по `Location`.

## Установка Apps Script (один раз)

1. Открыть Google-таблицу → *Расширения → Apps Script*.
2. Заменить содержимое `Code.gs` на [apps_script/Code.gs](apps_script/Code.gs), задать `SECRET`.
3. *Начать развёртывание → Новое развёртывание → Веб-приложение*:
   *Запуск от имени:* я; *У кого есть доступ:* все. Авторизовать. Скопировать URL `…/exec`.
4. Вставить URL и секрет в настройки плагина.
5. Проверка без Moodle: запустить `testInsert` в редакторе скрипта — в таблице появится тестовая строка (потом удалить).

После правок `Code.gs` нужно *Управление развёртываниями → карандаш → Новая версия*,
иначе `/exec` продолжает исполнять старую версию.

## Диагностика

- Очередь: `SELECT * FROM mdl_task_adhoc WHERE classname LIKE '%kabfeedbackgdoc%'` —
  `faildelay > 0` значит Google отвечал ошибкой, текст в `mtrace` лога cron.
- `GET <webhookurl>` должен вернуть `{"ok":true,"ping":"local_kabfeedbackgdoc"}`.
