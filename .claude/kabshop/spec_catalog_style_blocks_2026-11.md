## Что меняется

### 1. Разделы: иконка, боковая подпись, сворачивание

- Новые поля раздела (`local_kabshop_section`): `icon` (иконка из набора сайта: график, облачко, видео,
  люди, мозг, календарь, часы; пусто — без иконки), `sidelabel` (вертикальная подпись), `collapsed`
  («Свёрнут при открытии каталога»). Описание раздела — подзаголовок справа, как на сайте.
- Раздел — `<details>`: заголовок кликабелен, справа счётчик «(15)» и стрелка. Свёрнутый показывает
  только шапку. Ссылка из навигации по разделам и адрес с `#kabshop-section-N` раскрывают раздел.
  Первый (витринный) раздел с героем всегда открыт.

### 2. Блок «Об обучающей платформе Международной академии каббалы»

- После первого раздела. Заголовок, текст и необязательная ссылка «Читай далее» — настройки
  «Витрина: блоки каталога» (`about_title`, `about_text` HTML, `about_url`). По умолчанию — текст с
  kabacademy.com, ссылки нет (страницы WordPress уйдут). Пустой текст — блока нет.

### 3. Блок «Преподаватели академии»

- Перед юридическим подвалом. Настройки `teachers_title` и `teachers` — текст: каждый человек —
  абзац, первая строка «Имя | фото | ссылка» (фото и ссылка необязательны), дальше — о нём.
  Первый в списке — ведущий (крупно слева, «Читать полностью» при ссылке). Фото — имя файла из
  настройки «Фото преподавателей» (загрузка в Moodle) или адрес. По умолчанию — пять преподавателей с
  kabacademy.com, фото — `/kab/img/teachers/*` (статика сайта, как другие картинки уроков; в публичный
  репозиторий фото людей не кладём). Пусто — блока нет.

### 4. Стиль каталога

- Шрифты: добавить Montserrat Light и Open Sans Light/SemiBold (файлы с kabacademy.com, лицензия OFL)
  в `/kab/fonts/` — на dev сейчас; на проде Montserrat Light уже есть, Open Sans — при запуске кассы.
- Навигация — светлая полоса, пункты прописными с пунктирным подчёркиванием, как верхнее меню сайта.
- Герой — картинка слева, справа рамка-градиент, светлый заголовок, цена фиолетовым с разрядкой,
  фиолетовая кнопка «Подробнее».
- Карточки — прямые углы, без рамки, тень при наведении; заголовок Montserrat 300; описание Open Sans
  Light; цена прописными фиолетовым с разрядкой; «ПОДРОБНЕЕ ▷».
- Страницу товара в этот раз не трогаем (там работает соседняя доработка окна взноса).

## Изоляция и внешние зависимости

- Только `local_kabshop`: три поля раздела, страница настроек, файловая зона `teacherphotos` (публичная
  отдача, как картинки товаров), шаблоны и CSS каталога, иконки и логотип в `pix/` (свои ассеты
  академии с kabacademy.com). Ядро, тема и шлюзы не меняются.
- Статика сервера: `/kab/fonts/` (шрифты) и `/kab/img/teachers/` (фото) — заливаются вручную на dev
  сейчас и на прод при запуске кассы (пункт чек-листа запуска).
- Внешних запросов нет: всё отдаётся с edu.
