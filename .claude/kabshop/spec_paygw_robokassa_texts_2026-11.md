# Спека: тексты плагина `paygw_robokassa` — без донатов и «пожертвований»

16.11.2026. Решение владельца: «Да, убери» (плагин «всё время просит донаты»).

## Зачем

Плагин Snickser/moodle-paygw_robokassa 2.12 написан под сбор пожертвований:
- покупателю страница оплаты называется «Пожертвование», кнопка — «Пожертвовать!»,
  в письме — «Спасибо за ваше пожертвование»;
- администратору в форме шлюза и в настройках плагина показан блок автора: просьба о донате,
  кнопка YooMoney во фрейме, криптокошельки, картинка с внешнего сервера.

Мы продаём курсы, продавец — НФ. Слово «пожертвование» на странице оплаты неверно по сути
и мешает модерации магазина в Robokassa.

## Что меняем

Только нашу копию плагина в git (`public/public/payment/gateway/robokassa`):

| Файл | Правка |
|---|---|
| `lang/ru/paygw_robokassa.php`, `lang/en/paygw_robokassa.php` | «пожертвование» → «оплата» в строках для покупателя (`abouttopay`, `payment`, `paymore`, `sendpaymentbutton`, `message_success_completed`, `message_success_recurrent`, `password_text`, `skipmode_text`, `usedetails_text`); строка `donate` — только версия и ссылка на исходный плагин; новые строки `sno_*` |
| `classes/gateway.php` | список «Тип налогообложения» подписан словами вместо цифр 1–5; сохраняемые значения (`osn`, `usn_income`, …) прежние |
| `version.php` | 2026042101 → 2026042102, выпуск `2.12+kab1` — чтобы Moodle сбросил кэш строк |
| `README.md` | чем наша копия отличается от исходной |

Ключ строки `donate` оставлен, чтобы не трогать `settings.php` и вызов в форме: меньше расхождений
с исходным плагином при его обновлении.

## Изоляция

- Логика оплаты не меняется: `pay.php`, `callback.php`, `return.php`, `method.php`, шаблоны, JS,
  таблица `paygw_robokassa` и `db/upgrade.php` не трогаются.
- Сохранённые настройки шлюза (`mdl_payment_gateways.config`) читаются как раньше: ключи и значения те же.
- Другие плагины и ядро не затрагиваются.

## Внешние зависимости

- Нет. Наоборот, из админки уходят обращения к внешним адресам (YooMoney, shields.io).
- При обновлении плагина от автора правки вносятся заново (перечень — в README плагина).

## Выкладка

Git → dev-edu под пользователем dev → обновление через `/admin/index.php`. Прод — по общему плану
(`plan_prod_transfer_2026-11.md`, §3).

## Проверка

- Строки `payment`, `sendpaymentbutton`, `donate`, `sno_usn_income` на dev отдаются новыми
  (служба `core_get_string`, без входа).
- В файлах плагина не осталось «пожертв», «донат», `donat`, адресов кошельков и YooMoney.
- PHP-файлы проходят проверку синтаксиса.
- Не проверяется здесь: вид формы под администратором и страница оплаты вошедшим покупателем.
