# local_kabshop 0.6.0 — российская витрина, две кнопки оплаты, юридический блок

Дата: 16.11.2026. Ветка `claude/kabshop-ru-storefront`, база — `24d06ae` (0.5.1, то, что стоит на dev-edu).
Площадка: только dev-edu. На прод не выкладывается без отдельного согласования.

## Зачем

1. Robokassa подключает магазин, только если на сайте есть: открытая страница без переадресации,
   товары с реальными ценами, оферта, e-mail и телефон, полное имя продавца с ИНН/ОГРН в подвале,
   и всё, что связано с продажей, лежит на одном домене.
2. Продавцов двое. Рубли (Robokassa) принимает Некоммерческий фонд «Институт перспективных
   исследований» (РФ). Карту и PayPal (`checkout.kbb1.com`, Pelecard) — Ассоциация «Бней Барух
   Каббала ла-Ам» (Израиль). У каждого своя оферта и свои реквизиты.
3. Студенты из России заходят через VPN, поэтому страну по IP определить нельзя. Способ оплаты
   выбирает сам покупатель.

## Что делаем

**Рынок товара — по валюте.** Товар с ценой в `RUB` относится к российской витрине, продавец — НФ.
Товар в любой другой валюте (и бесплатный) — к основной витрине, продавец — ассоциация. Новых
полей в БД нет: рублёвый товар заводится обычной формой товара (валюта RUB, счёт Robokassa, тот
же курс).

**Российская витрина** — `/local/kabshop/ru.php`: только рублёвые товары из видимых разделов.
Это прямой адрес для модератора Robokassa и для ссылок из канала, бота и писем. Основная витрина
(`/local/kabshop/index.php` и главная сайта) рублёвые товары не показывает.

**Пара товара.** У товара с курсом пара — видимый платный товар того же курса на другом рынке.
Если таких несколько, берётся товар из того же раздела, затем по порядку сортировки. У товаров
без курса (сервис, пожертвование) пары нет.

**Две кнопки.** На странице товара, у которого есть пара, под основной кнопкой стоит вторая:
на основной витрине — «Оплатить в рублях», на российской — «Оплатить картой или PayPal». Она
ведёт на страницу парного товара. Покупка по паре записывает в тот же курс, потому что курс
у пары общий. Кнопки нет, если курс уже куплен.

**Описание по умолчанию.** Если у рублёвого товара пустые «Коротко» или «Описание», берутся
тексты пары — чтобы не вести одно описание в двух местах.

**Переключатель витрин.** Вверху каталога — ссылка на другую витрину. На основной она
появляется, только когда есть хотя бы один видимый рублёвый товар.

**Юридический блок** внизу каталога и страницы товара, видимый без кликов: продавец этого
рынка с реквизитами, e-mail и телефон, ссылки на оферту этого рынка и политику
конфиденциальности. Тексты продавцов и контактов — настройки плагина со значениями по умолчанию.

**Документы** — `/local/kabshop/legal.php?doc=offer|offer_ru|privacy`, открыты без входа. Тексты
лежат в `legal/*.html` плагина и взяты с kabacademy.com без правок по существу (страницы
83325, 607712 и 3, редакция 22.03.2026). Изменены только ссылки между документами — они ведут
на эти же страницы edu.

## Изоляция

- Меняется только `public/public/local/kabshop`. Ядро, тема, другие плагины не трогаются.
- Схема БД не меняется, `db/upgrade.php` без новых шагов. Поднимается только номер версии —
  ради сброса кэшей строк, шаблонов и стилей.
- Код оплаты (`classes/payment/service_provider.php`, подписки, купоны, заказы) не меняется:
  рублёвый товар — обычный товар со своей ценой, валютой и счётом.
- Пока рублёвых товаров нет, основная витрина выглядит как раньше, кроме юридического блока
  внизу.
- Глобальный подвал сайта (`additionalhtmlfooter`) не трогается.

## Внешние зависимости

- `paygw_robokassa` (принимает RUB) и платёжный счёт с этим шлюзом. На dev-edu счёт
  «Robokassa — тест (RU)» есть, шлюз на нём не настроен: ждёт логин и пароли магазина от
  владельца. До этого окно оплаты в рублях покажет, что способов оплаты нет.
- `paygw_kbb1` — карта и PayPal, без изменений.
- Модерация магазина в Robokassa и открытие сайта из России без Cloudflare — вне этой задачи.

## Чего здесь нет

- Пары для товаров без курса.
- Подсказки по часовому поясу и запоминания выбранной витрины.
- Автоматического пересчёта цены из долларов в рубли: рублёвую цену ставит владелец.
  На WordPress сейчас курс 75 ₽ за доллар (90 $ → 6 750 ₽).
- Переноса на прод.

## Проверка

1. Аноним: `/local/kabshop/ru.php` открывается без входа и переадресации, показывает рублёвый
   товар с ценой в ₽ и блок с НФ, ИНН/ОГРН, почтой, телефоном, ссылкой на оферту для РФ.
2. Аноним: основная витрина не показывает рублёвые товары, показывает блок ассоциации.
3. Страница долларового товара с парой — вторая кнопка «Оплатить в рублях»; страница рублёвого —
   «Оплатить картой или PayPal».
4. Три документа открываются без входа.
5. Вошедший покупатель: окно оплаты рублёвого товара — проверяет владелец после настройки шлюза.
