# local_kabshop 0.13.0: страница курса — начало, продолжительность, программа, состояние записи

22.11.2026. Запрос владельца: оформить товар-курс по образцу страницы курса kabacademy.com
(`/product/osnovy-kabbaly-chast-1-osen-2026/`), но проще. Явно показать дату начала,
продолжительность, список тем уроков, описание — в выделенном блоке. Для «Классической
каббалы» — «Запись завершена» / «Запись ещё не открыта» без кнопки записи: товар на витрине
всегда, с датой начала и с тем, можно ли записаться. Замечания к 0.12.0: у записанного на курс
пропадала вторая цена; весь текст шёл одной колонкой, под карточкой покупки — пусто.

## 1. Поля товара

| Поле | Что | На странице |
|---|---|---|
| `startdate` int | дата начала (полдень UTC выбранного дня — одна дата в любом часовом поясе); 0 — нет | карточка покупки: «Начало — 1 октября»; карточка каталога |
| `duration` char(100) | продолжительность текстом: «15 недель» | карточка покупки; карточка каталога |
| `program` text | темы уроков, по строке на тему (номера и маркеры в начале строки срезаются) | «В программе курса»: номера в голубых квадратах, две колонки |
| `about` text | короткий текст о курсе, абзац на строку | блок «Этот курс» под карточкой покупки, на цветной подложке |
| `salestate` char(10) | `auto` — по датам, `soon` — ещё не открыта, `closed` — завершена | блок состояния вместо кнопки |
| `saleopen`, `saleclose` int | окно записи для `auto`; 0 — без границы | «Откроется 15 января», «Запись открыта до 30 сентября» |
| `salenote` char(255) | пояснение к закрытой записи: «Следующий поток — весной» | под заголовком блока состояния |

Все поля необязательны. Товар без `program` и `about` выглядит как раньше (карточка слева
липнет при прокрутке, описание справа).

## 2. Состояние записи

`catalog::sale_state($product)` → `open | soon | closed`:

- `salestate = soon | closed` — как задано вручную;
- иначе по датам: раньше `saleopen` — `soon`, с `saleclose` — `closed`, иначе `open`;
- внешняя ссылка (`kind = external`) — всегда `open`.

Не `open` — на странице вместо кнопки блок «Запись ещё не открыта» / «Запись завершена»,
нет выбора валюты, суммы на выбор, промокода. Уже записанному — «Перейти к курсу», подписчику —
управление подпиской, как раньше. В каталоге товар остаётся, на карточке — пометка состояния.

Закрытую запись не обойти мимо страницы: `enrol.php`, `donate.php`, `coupon.php` возвращают
на страницу товара; `service_provider::get_payable` бросает `saleclosed` — на тех же условиях,
что условие записи (`noprereq`): только живой покупатель, не автосписание, не cron, не
управляющий витриной. Шлюзы зовут `get_payable` только в начале оплаты (kbb1 `pay.php`,
Robokassa `pay.php`/`method.php`, PayPal — до списания), выдача оплаченного (`deliver_order`)
состояние записи не проверяет: кто начал платить до закрытия, получит курс.

Ручная выдача (`grant.php`) и автосписания не ограничиваются.

## 3. Страница товара

- **Карточка покупки**: сверху «Начало» и «Продолжительность» с иконками (календарь, часы из
  `pix/icons`), ниже цена. У товара с двумя ценами вторая показана всегда — «90,00 $ или
  6 750,00 ₽», в том числе записанному и при закрытой записи (раньше была видна только в
  переключателе валют, а он скрыт у записанного). **Правка 23.11:** когда
  переключатель валют виден, «или 90,00 ₽» рядом с ценой не выводится — обе валюты уже в
  переключателе (замечание владельца на скриншоте товара «Пожертвование»).
- **Подпись вместо «Бесплатно» (правка 23.11, 2026112300):** у бесплатного товара непустая «Подпись
  к цене» (`pricelabel`) выводится **вместо** «Бесплатно» — в карточке покупки, в каталоге и в
  «Управлении»; кнопка записи тогда «Записаться» вместо «Записаться бесплатно». Пустая подпись —
  всё как раньше. У платного товара подпись по-прежнему идёт после цены («в месяц»). Зачем:
  владелец 23.11 — у «Классической каббалы. Часть 1» (прод, товар 55) слово «бесплатно» не нужно,
  писать «Вход свободный»; для остальных бесплатных товаров не решено, они остаются «Бесплатно».
  Изоляция: схема не меняется, бамп версии — только ради кэша языковых строк (новая строка `enrol`);
  товары с пустой подписью не меняются. Обложку товара 55 (фото с Борей) владелец попросил отразить,
  чтобы он смотрел в центр, — это данные: отражённый файл загружен формой товара.
- **Адрес обложки и фото преподавателя — с `?rev=`** (первые 8 знаков хэша содержимого): pluginfile
  отдаёт картинку с `max-age=86400`, Cloudflare держит её сутки по адресу, и замена файлом с тем же
  именем (обложка товара 55) была не видна. pluginfile.php параметр игнорирует; схема не меняется.
- **Картинка курса у товара без своей обложки — через pluginfile витрины (23.11).** Было:
  `course_summary_exporter::get_course_image` → `pluginfile.php/<ctx курса>/course/overviewfiles/…`;
  на проде `forcelogin=1`, ядро редиректит такие адреса на вход, и гость (витрина ему открыта)
  видел битые картинки у всех товаров «Самообучения» и т. п. Стало: адрес
  `pluginfile.php/1/local_kabshop/courseimage/<id товара>/<имя файла>?rev=<8 знаков хэша>`,
  обработчик берёт первую картинку из `overviewfiles` курса товара (`courseid`) и отдаёт её без
  входа, как обложки витрины. Отдаёт только для видимого товара (скрытый — тем, у кого
  `local/kabshop:manage`); имя файла в адресе — для кэша, на выбор файла не влияет. Через
  витрину видны только картинки курсов, привязанных к товарам, — они и так на витрине.
  Заодно: обработчик фото преподавателей искал файл в области `image` вместо `teacherphotos`
  (файлов там пока нет ни на dev, ни на проде — фото не показалось бы при первой загрузке).
  Изоляция: схема и версия не меняются, ядро не трогается; при `forcelogin=0` вид прежний.
- **Без пустого места под карточкой** (товар с `program` или `about`): сверху карточка и
  справа от неё «В программе курса»; ниже на всю ширину — блок «Этот курс» (абзацы колонками)
  и описание в две колонки, заголовки и линии идут через обе. Без программы «Этот курс» встаёт
  справа от карточки. Первый вариант — две колонки на всю длину, как на образце, — отброшен:
  на живом тексте левая колонка кончалась на ~800px раньше правой.
- Товар без `program` и `about` — как раньше: описание справа, карточка липнет при прокрутке.
- **Каталог**: на карточке и на герое раздела — строка «Начало — 1 октября · 15 недель» и
  плашка «Запись завершена» / «Запись ещё не открыта» на обложке.
- Телефон: шапка, карточка, программа, «Этот курс», описание — одной колонкой.

## 4. Изоляция

- Схема: только новые поля `local_kabshop_product`, шаг апгрейда 2026112200. Старые поля,
  заказы, подписки, купоны не трогаются; у существующих товаров новые поля пусты → запись
  открыта, вид прежний (кроме второй цены в карточке).
- Прод не тронут: плагина на проде нет.
- Данные dev: товар 1 — программа и «Этот курс» переносятся из описания в новые поля (SQL,
  бэкап `_kab_bk20261122_kabshop_product`).
