# local_kabshop 2026112304: сумма по умолчанию у взноса

Запрос владельца 23.11.2026: «во взнос добавить сумму по умолчанию, которую мы сами указываем».
Сейчас у товара с суммой на выбор («Взнос в фонд МАК» — 25/50/100/250 $, «Взнос за курс»)
заранее выбрана всегда первая кнопка суммы.

## Поля товара

| Поле | Что |
|---|---|
| `defaultamount` number(12,2), 0 | сумма, выбранная заранее, в основной валюте; 0 — не задана |
| `altdefaultamount` number(12,2), 0 | то же во второй валюте (рубли) |

В форме — сразу под «Готовыми суммами» и «Готовыми суммами во второй валюте», видны там же, где они
(сумма на выбор; вторая — если задана вторая валюта).

## Поведение на странице товара

- Сумма совпадает с одной из готовых — заранее выбрана эта кнопка.
- Не совпадает — вписана в поле «Другая сумма», кнопки не выбраны.
- Не задана (0) — как раньше: первая кнопка.
- Если человек уже вводил сумму (вернулся после ошибки) — его сумма важнее.
- Вторая валюта: `catalog::alt()` подставляет `altdefaultamount` вместо `defaultamount`, как уже
  делает с ценой, готовыми суммами и счётом.

Проверка формы: заданная сумма не меньше минимума (цены) своей валюты и не больше `MAX_AMOUNT`.
Без второй валюты `altdefaultamount` обнуляется при сохранении, как `altpresets`.

## Изоляция

- Схема: два поля с нулём по умолчанию, шаг апгрейда `add_field` с `field_exists` → у всех
  товаров 0 → вид прежний.
- Не трогается: окно «Безвозмездная помощь» (там своя сумма по умолчанию — настройка
  `freedonation_default`), оплата, `donate.php` (сумма приходит из формы, как раньше), заказы.

## Внешние зависимости

Нет: только форма товара и страница товара.
