# Касса 0.17.0 — ответы на вопросы по админке витрины (26.11.2026)

Источник — документ «Админка витрины эдукабакадеми» (Google Docs, 15 пунктов). Ниже — что делаем
по каждому пункту, изоляция и внешние зависимости. Ветка — от `claude/kabshop-staff-reports`
(0.16.0 = прод с 26.11).

## Изоляция и зависимости

- Меняется только `local_kabshop` (+ одна строка в `local_kabsignup`: гость не идёт в `buy.php` за
  товаром с любым ограничением видимости, не только с условием записи).
- Схема БД: новые поля, данных не меняем. `upgrade.php` шаг 2026112700, поля с NULL/дефолтами —
  у существующих товаров и разделов поведение прежнее.
- Шлюзы (kbb1, Robokassa) не трогаем: таблицы `paygw_kbb1` и `paygw_robokassa` только читаем.
  Возврат денег — по-прежнему в кабинете шлюза, сайт его не делает.
- Внешних сервисов нет. WS `local_kabshop_check_access` смотрит `status = 'ok'` — возврат
  (`refunded`) и отзыв (`revoked`) доступа к AI MAK не дают, как и раньше отзыв.

## По пунктам

1. **Страница товара.** Справа от карточки — «Этот курс» (одной колонкой); «В программе курса» —
   ниже на всю ширину; описание — одной колонкой (без CSS columns). Без «Этот курс» справа, как
   раньше, программа.
2. **Поток на странице товара** — первым пунктом в карточке («Поток — Весна 2027»), значок людей.
3–5. **Условия видимости** у раздела и у товара: курсы (записан на любой), глобальные группы
   (состоит в любой), e-mail (адрес в списке) и режим «любое из условий» / «все условия».
   Пустая группа не участвует. Управляющий витриной видит всё.
   - Товар: условия = видимость в каталоге **и** право купить/записаться (как прежнее «Условие
     записи»: `prerequisite_ok` проверяет всё). Курсовое условие сохраняет прежний смысл: свой
     курс товара засчитывается, списки условий товаров одного курса объединяются.
   - Раздел: только каталог (как галочка «Видимость»: товары по прямой ссылке открываются).
   - Раздел, где для человека нет ни одного товара: поле «Текст, если доступных товаров нет».
     Пусто — раздел скрыт (как сейчас), иначе — раздел с этим текстом. Заглушка — только когда
     товары у раздела на этом рынке есть, но все скрыты условиями.
6. **Все заказы покупателя:** `orders.php?userid=` (фильтр с плашкой «Покупатель: …, сбросить»),
   ссылки из заказа и из списка; в профиле пользователя для управляющего — «Заказы витрины».
7. **Перенос заказа на другой аккаунт** (`order.php`, действие `transfer`, e-mail целевого
   аккаунта): покупка, её подписка с продлениями, платежи Moodle (`payments.userid`), использование
   купона, строки шлюзов (`paygw_kbb1.userid`) — на новый аккаунт; запись на курс товара —
   новому (срок — как был у старого), у старого снимается ручная запись, если у него не осталось
   других действующих покупок этого курса. В заметку заказа — «перенесён с … (кто)». Транзакция.
8. **Незавершённые оплаты:** добавить Robokassa (`paygw_robokassa.success = 0` + `payments`),
   убрать технические строки импорта подписок WP (`paygw_kbb1.status = 'imported'`, сейчас
   показались бы мусором). Скриншот в документе от 24.11 12:07 — тогда незавершённая была одна.
9. **Товар в незавершённых оплатах** — колонка «Товар» (зона `custom` → intent → товар, `product`/
   `productalt` → товар, `renewal` → подписка → товар).
10. **«Мои подписки»:** фраза про доступ — только если среди подписок есть дающая доступ (курс
    товара или товар из «Товары, дающие доступ»); иначе «После отмены деньги больше не списываются».
11. **Возвраты:** деньги возвращаются в кабинете шлюза (Robokassa — «Возврат», карта/PayPal —
    через бухгалтерию в сервисе оплаты организации). На сайте — новое действие «Отметить возврат»:
    статус заказа `refunded`, причина, подписка останавливается, флажок «Снять доступ к курсу»
    (по умолчанию да, если у товара есть курс). В списке заказов — «· возврат», сумма «итого»
    без возвратов и отзывов. Отчёт секретарю и так берёт только `status = 'ok'`.
12. **Видимость из списка** — значок глаза у товара и у раздела (POST с sesskey).
13. **Номера 10, 20, 30** — это порядок сортировки с шагом 10 (чтобы вставлять между). В списке
    теперь позиция 1, 2, 3 и стрелки «выше/ниже» (меняют местами сортировку соседей).
14. **Заголовок блока «Этот курс»** — поле товара «Заголовок блока»; пусто — «Этот курс».
15. **Счётчик неудач** — подписи и подсказка: автосписание повторяется через 20 ч, после 3 неудач
    подряд подписка становится «Остановлена»; сброс нужен, когда возвращаете подписку в «Активна»
    вручную, иначе следующая же неудача снова её остановит.
