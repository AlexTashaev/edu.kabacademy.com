**Страницы менялись после клипов (24.09.2026, сессия «Схемы по курсу»):** в 17879 и 17880 вместо
плашек «Схема 1–3» вставлены inline-схемы (класс `kab-figure`, исходники `.claude/course238/lecture1/`,

Поэтому снимки `before/` и `after/` — исторические: **не пересобирать из них**, перед новой правкой
снимать актуальный `contents` из БД и вставлять клипы в него. Правило владельца для всех текстов курса,
включая подписи к клипам: не «Рав», а «Михаэль Лайтман» (в `build_clips.py` подписи уже исправлены).

Клип 07 («Сверху вниз и снизу вверх», 2019) есть только в папке `01/Видео/`, в upscaled/web его нет —
глава 2 ждёт его отдельно. Плашки «Схема 1–3» (заказ дизайнеру) не тронуты.

- `build_clips.py` — сборка HTML и SQL из дампов (дамп `mysql -e`: `\n` экранирован, CR сырой).
- `before/`, `after/` — страницы до и после (LF).
- `upd_lesson1_clips.sql` — бэкап `_kab_bk20260924_l1960_pages` + UPDATE трёх страниц (hex-литералы, CRLF как у редактора).
- Применение: `scp upd_lesson1_clips.sql web-18:/tmp/` → `/tmp/kab_moodle_sql2.sh "$(cat /tmp/upd_lesson1_clips.sql)"`.
- Формат встраивания как в остальных курсах: `<iframe src="https://drive.google.com/file/d/ID/preview" width="100%" height="480" allow="autoplay">` —
  под него в Boost SCSS уже есть правило aspect-ratio 16/9.
- Доступ: файлы в `web/` пока расшарены только на команду — для студентов нужно «Доступ по ссылке (читатель)»
  на папку `web/` (у старых видео курсов стоит `anyone: reader`).
