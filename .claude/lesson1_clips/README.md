Тег (пример, клип 05):

```html
<video class="nomediaplugin" controls="controls" controlslist="nodownload" preload="metadata" playsinline="playsinline"
  oncontextmenu="return false;" poster="https://files.kabbalahmedia.info/kabacademy/MAK/Lesson-01-clip-01-05.jpg"
  style="display: block; width: 100%; aspect-ratio: 4 / 3; background: #000;">
  <source src="https://files.kabbalahmedia.info/kabacademy/MAK/Lesson-01-clip-01-05.mp4" type="video/mp4"></video>
```

- `nomediaplugin` — фильтр медиа Moodle не переписывает тег (как в гостиных); `aspect-ratio` — из ffprobe, без полос.
- Файлы faststart (moov перед mdat), сервер отдаёт Range (206) — перемотка работает без полной загрузки.
- `filer/swap_to_filer.py` — по свежему дампу страниц (`SELECT TO_BASE64(contents)`) строит `upd_lesson1_filer.sql`:
  бэкап `_kab_bk20260927_l1960_pages` и шесть `UPDATE … REPLACE()` по точной строке Drive-iframe (hex-литералы),
  поэтому параллельные правки других частей страницы не затираются; в конце — сверка MD5 с ожидаемым.
- `filer/page_*.html` — страницы после замены (как в БД на 27.09.2026, до правки главы 3 в редакторе).
- `nocaptions/drop_captions.py` → `upd_lesson1_nocaptions.sql` — тот же приём: бэкап `_kab_bk20260927b_l1960_pages`
  и шесть `REPLACE()` абзацев-подписей на пустую строку; `nocaptions/page_*.html` — итоговые страницы.
- Главу 3 (17881) 27.09 пересохраняли через редактор Moodle (заголовок «Почему знание было скрыто»): редактор
  выкидывает из `<video>` атрибуты `controlslist`, `playsinline`, `oncontextmenu` и переносит `<source>` на свою строку.
  Видео от этого не ломается; полагаться на эти атрибуты не стоит.

Проверено: MD5 страниц в БД совпал с ожидаемым; в headless Edge все шесть видео отдают метаданные
(размеры и длительность верные); на странице урока плееры с обложками отображаются.
