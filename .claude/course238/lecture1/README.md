## Как устроено

- `svg/make_svg.py` — генератор чертежей → `public/public/kab/img/l1/schema{2,3}{,-m}.svg`.
  В каждый SVG встроено подмножество Montserrat (woff2, только нужные буквы), поэтому файл
  одинаково рисуется в `<img>` везде. Шрифты-исходники — `svg/_fonts/` (в git не лежат,
  скрипт скачает их с `edu.kabacademy.com/kab/fonts/`).
- Два варианта каждого чертежа: широкий и узкий `-m` (портретный, крупнее текст).
  В разметке `<picture>`: узкий при ширине окна до 767px. `<img>` с `width: auto; max-width: 100%` —
  чертёж не растягивается больше родного размера.
- `schemas/schema<N>.html` — фрагмент для вставки в страницу. Одинарных кавычек быть не должно.
  Адреса картинок абсолютные (мобильное приложение Moodle) и с `?v=N` — при правке чертежа
  поднять версию, иначе браузеры покажут старый файл из кэша.
- `build.py` — **собирает от свежего контента из БД**: снимает страницы с prod, находит блоки
  `<div class="kab-figure">`, по подписи «Схема N.» заменяет их фрагментами, остальное не трогает.
  `UPDATE` защищён `MD5(contents)`: если страницу успели изменить, обновится 0 строк.
  Заодно заменяет слово «Рав» на «Михаэль Лайтман» (правило заказчика 24.09.2026).
- `current/` — что было на prod при последней сборке; `pages/` — результат;
  `orig/` — исторический снимок до первых схем, в сборке не участвует.

Страницы урока правят параллельно: клипы ставит сессия `.claude/lesson1_clips/`
(ветка claude/lecture-1-video-matching-322c33), главу 3 владелец правит в редакторе Moodle.
Поэтому любые снимки страниц быстро устаревают — собирать только через `build.py`.

## Применить / откатить

```
python .claude/course238/lecture1/svg/make_svg.py
python .claude/course238/lecture1/build.py --only 2 3
ssh web-18 'mkdir -p /sites/edu.kabacademy.com/public/public/kab/img/l1'
scp public/public/kab/img/l1/*.svg web-18:/sites/edu.kabacademy.com/public/public/kab/img/l1/
scp .claude/course238/lecture1/upd_lesson1960.sql web-18:/tmp/
ssh web-18 '/tmp/kab_moodle_sqlfile.sh /tmp/upd_lesson1960.sql'
```

В выводе SQL смотреть `updated_rows`: 1 — применилось, 0 — страница изменилась, пересобрать.
Бэкап страниц создаётся один раз в день: `_kab_bk<дата>s_l1960_pages`. Откат — `rollback_lesson1960.sql`.
Кэш чистить не нужно: страницы урока читаются из БД на каждом показе.

Превью: `python build.py --no-fetch --preview-dir DIR` (в DIR нужны `fonts.css`, `fonts/` и `l1/*.svg`),
статик-сервер и скриншоты headless Edge; узкая колонка — `preview.html?w=360` при окне до 767px.
