## Как устроено

- `make_assets.py` — из поставки (`C:\Users\tashaev\Downloads\schemes`) кладёт в
  `public/public/kab/img/schemes/` анимацию `<код>.webp` как есть и неподвижный кадр
  `<код>-static.png` (самый заполненный кадр APNG, 256 цветов). GIF не используется.
- `schemas/schema<N>.html` — фрагмент: карточка `kab-figure`, `<picture>` (неподвижный кадр при
  «уменьшить движение», WebP, в остальных случаях PNG), ссылка «открыть крупнее» — на телефоне
  подписи на схемах мелкие, по нажатию схема открывается целиком. Подпись «Схема N.» — по ней
  сборщик находит блок.
- `build.py` — для каждой цели (`l1962`, `l1960`, `b962`) снимает свежий контент с prod, меняет
  только блоки `kab-figure` по номеру схемы, UPDATE защищён `MD5` (`updated_rows = 0` → пересобрать).
  `current/` — что было на prod, `pages/` — что стало, `upd_*.sql` / `rollback_*.sql`.

```
ssh web-18 '/tmp/kab_moodle_sqlfile.sh /tmp/upd_l1962.sql'   # и так же l1960, b962
```

Бэкапы 30.09.2026: `_kab_bk20260930d_l1962`, `_kab_bk20260930d_l1960`, `_kab_bk20260930d_b962`.
Откат — `rollback_<цель>.sql` тем же раннером. При замене файла схемы поднять `?v=N` во фрагменте.
