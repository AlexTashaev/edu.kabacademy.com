предыдущий урок (лекция, тест, «Отклик недели») должен быть пройден к 23:59 среды

лекции 1, 4–7 и «Отклик недели» 1, 3–7. Им передвинули `completionexpected`

с 23:59.

- закрытие «Вопроса по теме урока N к вебинару» в четверг в 19:00;
