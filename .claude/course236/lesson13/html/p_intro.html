Двенадцать недель в курсе повторялась одна мысль, каждый раз с новой стороны: новый орган чувств проверяется только на других (урок 3), группа — место, где методика применяется (урок 8), «Книга Зоар» написана из соединения (урок 10), своя часть проявляется только относительно других (урок 12).

Этот урок — о распространении каббалы в мире: почему оно часть духовного развития самого человека.

«Абсолютная обязанность возложена на каждого – заниматься каббалой, без которой человек не достигнет цели своего творения».

— Бааль Сулам, «Предисловие к книге „Уста мудрого“»

Цель распространения науки каббала – это раскрытие Творца творениям в этом мире.
